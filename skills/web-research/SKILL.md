# 公网调研 Skill

当你需要最新新闻、公开网页或官网信息时：

1. **先搜索**：调用 `web_search`，用清晰关键词获取标题/链接/摘要。
2. **再核验**（可选）：对重要链接用 `http_get`（仅 allowlist 主机）读取正文片段。
3. **区分来源**：明确标注「公网」结果；不要把公开信息伪装成企业内部政策。
4. **诚实降级**：搜索失败或未配置 API Key 时，说明无法联网，不要编造网页内容。

输出使用简洁中文；结论在前，来源链接在后。

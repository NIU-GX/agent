# 知识库问答 Skill

当你处理企业内部政策、流程、规范类问题时：

1. **先检索**：调用 `retrieve`，用用户原话或改写查询获取上下文。
2. **再回答**：只基于检索结果作答；没有命中时明确说明「知识库未覆盖」。
3. **引用**：回答中点明来源文档/片段，不要编造条文编号。
4. **外链核验**（可选）：若需核对公开 HTTPS 页面，可在本 Skill 激活后使用 `http_get`（仅 allowlist 主机）。

输出使用简洁中文；先给结论，再列依据。
